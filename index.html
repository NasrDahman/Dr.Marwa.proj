GitHub: مستودع أكوادك الآمن

يوفر لك مساحة تخزين سحابية لملفات موقعك مع سجل تاريخي يحفظ كل تعديل تقوم به. من خلال المتصفح فقط، يمكنك إضافة الملفات وحذفها وإدارتها بسهولة دون لمس الطرفية.

  • سحب وإفلات للملفات عبر المتصفح (Drag & Drop)
  • خوادم سحابية فائقة الأمان ومجانية تماماً

Vercel: سرعة النشر الخارقة

المنصة الأحدث عالمياً لنشر الواجهات الأمامية. تتصل بمستودع GitHub مباشرة، وبمجرد إجراء أي تعديل هناك، يتم بناء ونشر الموقع عالمياً على شبكة خوادم سريعة (Edge Network).

  • شهادة أمان SSL مجانية تلقائياً لجميع المواقع
  • دومين مجاني دائم (مثل: project.vercel.app)

المرحلة الأولى

إنشاء مستودع GitHub ورفع الملفات بالسحب والإفلات

توجه إلى موقع GitHub.com بعد تسجيل دخولك:

  1. اضغط على زر New ذي اللون الأخضر لإنشاء مستودع جديد (New Repository).
  2. اكتب اسماً مناسباً لمشروعك، وتأكد من اختيار الحالة Public.
  3. في الصفحة التالية، اختر رابط "uploading an existing file".
  4. اسحب ملفات موقعك (تأكد من وجود ملف باسم index.html رئيسي) وأفلتها في المتصفح، ثم انقر Commit changes.
رفع الملفات عبر واجهة المتصفح (Web UI)
المرحلة الثانية

التسجيل في منصة Vercel بنقرة واحدة

الآن ننتقل إلى محطة الإطلاق الحقيقية عبر Vercel.com:

  • افتح المتصفح وانتقل إلى vercel.com، ثم انقر على Sign Up في أعلى اليمين.
  • اختر التسجيل مباشرة بواسطة Continue with GitHub لاختصار عملية الربط تماماً.
  • وافق على صلاحية الوصول (Authorize Vercel) لكي تتمكن المنصة من قراءة مستودعاتك السحابية.
تسجيل الدخول والتفويض السحابي
المرحلة الثالثة

استيراد المشروع (Import Project)

داخل لوحة تحكم Vercel (Dashboard):

  1. انقر فوق زر Add New... ثم اختر Project.
  2. ستظهر لك قائمة بجميع مستودعات GitHub الخاصة بك؛ ابحث عن اسم المستودع الذي رفعته للتو.
  3. اضغط على زر Import الموجود بجانب اسم المستودع.
  4. ستظهر إعدادات التكوين (Project Name, Framework Preset)؛ إذا كان موقعك ملفات عادية (HTML/CSS/JS)، اترك كل الإعدادات الافتراضية كما هي دون تعديل.

النشر (Deploy) واستلام الرابط المباشر

اللمسة السحرية لإطلاق موقعك:

  • اضغط على الزر الأزرق الكبير Deploy.
  • انتظر ثوانٍ معدودة؛ ستشاهد ألعاباً نارية شاشية تفيد بنجاح النشر مع عبارة Congratulations!.
  • انقر على صورة المعاينة أو الرابط المباشر لتفتح موقعك الجديد الذي أصبح متاحاً لأي شخص حول العالم مجاناً وبأعلى أداء!

الأسئلة الأكثر شيوعاً

إجابات مباشرة على استفسارات النشر والاستضافة السحابية

هذه هي الميزة الأقوى في Vercel! بمجرد أن تعدل أو ترفع ملفاً جديداً في مستودع GitHub عبر المتصفح، سيكتشف Vercel التغيير تلقائياً ويقوم بإعادة بناء الموقع ونشره في أقل من دقيقة دون أي تدخل يدوي منك.
لا، الخدمة مجانية تماماً للمشاريع الشخصية وحافظات الأعمال (Portfolio). ستحصل على استضافة مجانية، باندويث واسع، وشهادة SSL لحماية الموقع دون الحاجة لإدخال أي بطاقة بنكية.
خوادم الويب العالمية مبرمجة لتبحث افتراضياً عن ملف يُدعى index.html في المجلد الرئيسي ليكون الصفحة الأولى (الصفحة الرئيسية) التي يراها الزائر عند فتح الرابط.
