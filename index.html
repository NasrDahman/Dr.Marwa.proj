حفظ الكود على GitHub

يعمل GitHub كخزنة سحابية لأكوادك. يحمي ملفاتك من الضياع، ويتيح لك تتبع كل تعديل تقوم به ومشاركته مع العالم.

النشر التلقائي (CI/CD)

بمجرد ربط Vercel بـ GitHub، أي تعديل تقوم برفعه (Push) إلى GitHub سيظهر في موقعك المباشر خلال ثوانٍ دون أي تدخل يدوي!

مجاني + شهادة SSL

تحصل على رابط مجاني آمن يبدأ بـ https:// مع سرعة فائقة بفضل شبكة الخوادم العالمية (CDN) الخاصة بـ Vercel.

الدليل العملي المصور

كيف تستضيف موقعك في 4 خطوات؟

الخطوة الأولى

تجهيز ملفات موقعك (index.html)

قبل أي شيء، تأكد من أن ملف الصفحة الرئيسية لموقعك يحمل الاسم index.html لأن المتصفحات وخوادم الاستضافة تبحث عن هذا الملف تلقائياً عند فتح الرابط.

  • ضع جميع ملفاتك (HTML, CSS, JS) في مجلد واحد.
  • تأكد من صحة مسارات الصور والملفات.
  • قم بتحميل برنامج Git على جهازك إذا لم يكن مثبتاً.
الخطوة الثانية

إنشاء مستودع جديد على GitHub

ادخل إلى حسابك في GitHub وأنشئ مستودعاً جديداً (New Repository) ليكون الحاضن لملفات موقعك.

  1. افتح موقع github.com/new.
  2. اكتب اسم المشروع في خانة Repository name (مثلاً: nasrallah-website).
  3. اجعل المستودع عاماً (Public) أو خاصاً (Private) كما تفضل.
  4. اضغط على الزر الأخضر Create repository بالأسفل.
الخطوة الثالثة

رفع الملفات عبر الأوامر أو المتصفح

يمكنك رفع الملفات مباشرة عبر المتصفح بالضغط على uploading an existing file، أو بالطريقة الاحترافية عبر موجه الأوامر (Terminal): 

git init
git add .
git commit -m "First commit by Nasrallah"
git branch -M main
git remote add origin https://github.com/username/repo.git
git push -u origin main
الخطوة الرابعة والأخيرة

ربط المستودع بمنصة Vercel

الآن تأتي اللحظة الحاسمة لتحويل الكود إلى موقع حي يعمل على الإنترنت:

  1. توجه إلى موقع Vercel.com وسجل الدخول باستخدام حسابك في GitHub.
  2. من لوحة التحكم اضغط على Add New... ثم اختر Project.
  3. ستظهر لك قائمة مشاريعك على GitHub، اضغط على زر Import بجانب مشروعك.
  4. اضغط على زر Deploy وانتظر بضع ثوانٍ.. ومبارك عليك موقعك الجديد! 🎉
تجربة حية

محاكي النشر التفاعلي (GitHub ➔ Vercel)

اكتب اسم مشروعك واضغط على زر "ابدأ المحاكاة" لترى كيف يتفاعل Vercel مع GitHub لحظة بلحظة!

bash - nasrallah@deployment:~

// اضغط على "ابدأ المحاكاة" لتشغيل عملية الرفع والاستضافة...
