المرحلة الأولى

رفع ملفات الموقع إلى GitHub

سنقوم بإنشاء مستودع جديد وسحب ملفات موقعك إليه مباشرة عبر المتصفح كما ترفع أي ملف على الإنترنت.

1

إنشاء مستودع جديد (New Repository)

بعد تسجيل الدخول إلى حسابك في GitHub، اضغط على علامة (+) في أعلى يمين الشاشة، ثم اختر New repository من القائمة المنسدلة.

من الواجهة العلوية للموقع
2

تسمية المشروع وتحديد الخصوصية

اكتب اسماً لموقعك في خانة Repository name، وتأكد من اختيار Public، ثم فعّل خيار Add a README file، واضغط الزر الأخضر Create repository.

يجهز لك مجلداً جاهزاً للرفع
3

سحب وإفلات الملفات (Upload Files)

داخل صفحة المستودع، اضغط زر Add file ثم اختر Upload files. اسحب ملفات موقعك (تأكد أن الملف الرئيسي اسمه index.html) وأفلتها في المربع، ثم اضغط Commit changes.

بدون كتابة أي كود Git!
المرحلة الثانية

ربط الموقع واستضافته عبر ▲ Vercel

الآن بعد أن أصبحت ملفاتك على GitHub، سنقوم بربطها بمنصة Vercel لنشر الموقع والحصول على رابط مباشر في ثوانٍ.

4

الدخول بحساب GitHub

افتح موقع vercel.com واضغط على Sign Up أو Log In، ثم اختر الزر الأسود Continue with GitHub ليتم الربط المباشر بين الحسابين بضغطة زر.

ربط تلقائي آمن وسريع
5

استيراد المشروع (Import)

من لوحة تحكم Vercel، اضغط على زر Add New... ثم اختر Project. ستظهر لك قائمة بمستودعاتك على GitHub، ابحث عن اسم موقعك واضغط زر Import بجانبه.

جلب الملفات مباشرة من GitHub
6

النشر الفوري (Deploy)

لا تغير أي إعدادات! فقط اضغط على الزر الأزرق/الأبيض الكبير Deploy. انتظر ثواني معدودة وستظهر لك احتفالية النجاح مع رابط موقعك الرسمي (.vercel.app)!

يتحدث الموقع تلقائياً كلما عدلت ملفاتك
