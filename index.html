لماذا نستخدم GitHub و Vercel؟

منصتان تعملان معاً لتسهيل إدارة موقعك الإلكتروني ونشره على الإنترنت دون الحاجة إلى خادم خاص.

GitHub

منصة لحفظ وإدارة ملفات مشروعك البرمجي عبر الإنترنت، باستخدام المستودعات (Repositories).

  • حفظ ملفات موقعك بأمان.
  • رفع الملفات من المتصفح مباشرة.
  • تتبع التعديلات والتحديثات.

Vercel

منصة استضافة حديثة تحول ملفات مشروعك إلى موقع إلكتروني متاح للجميع عبر رابط مباشر.

  • نشر موقعك بسهولة.
  • الحصول على رابط مجاني.
  • تحديث الموقع تلقائياً عند تحديث GitHub.

01

رفع ملفات موقعك إلى GitHub

تجهيز المشروع وإنشاء Repository ورفع الملفات

أولاً: الدخول إلى GitHub

  1. افتح موقع GitHub.com.
  2. سجل الدخول إلى حسابك، أو أنشئ حساباً جديداً إذا لم يكن لديك حساب.
  3. بعد تسجيل الدخول، اضغط على علامة (+) الموجودة أعلى الصفحة.
  4. اختر New repository لإنشاء مستودع جديد.

ثانياً: إنشاء المستودع

  1. اكتب اسماً للمشروع، مثلاً: my-first-website.
  2. اختر Public حتى يكون المستودع متاحاً للاستيراد بسهولة.
  3. يمكنك تفعيل خيار Add a README file إن رغبت.
  4. اضغط على زر Create repository.

ثالثاً: رفع ملفات الموقع Drag & Drop

  1. افتح المستودع الذي أنشأته.
  2. اضغط على Add file.
  3. اختر Upload files.
  4. اسحب ملفات موقعك من جهازك وأفلتها داخل منطقة رفع الملفات.
  5. تأكد من وجود ملف index.html في المجلد الرئيسي للمشروع.
  6. انتظر اكتمال الرفع، ثم انزل إلى الأسفل واضغط على Commit changes.
نصيحة مهمة: يجب أن يكون ملف index.html في جذر المستودع (Root Directory)، وليس داخل مجلد فرعي، حتى يسهل على Vercel اكتشاف الصفحة الرئيسية.

02

إنشاء حساب على Vercel

الدخول إلى منصة الاستضافة وتجهيز حسابك

الدخول إلى منصة Vercel

  1. افتح الموقع الرسمي: Vercel.com.
  2. اضغط على Sign Up لإنشاء حساب جديد.
  3. ستظهر لك خيارات التسجيل المختلفة.
  4. اختر Continue with GitHub لتسجيل الدخول باستخدام حساب GitHub.
  5. إذا ظهرت نافذة تفويض الصلاحيات، راجعها ثم وافق على ربط الحساب.
معلومة: يفضل استخدام حساب GitHub نفسه الذي رفعت إليه ملفات موقعك لتسهيل عملية الربط والاستيراد.
إنشاء حساب Vercel
03

ربط GitHub مع Vercel واستيراد المشروع

اختيار المستودع وربطه بمنصة الاستضافة

استيراد المشروع

  1. بعد تسجيل الدخول إلى Vercel، ستظهر لك لوحة التحكم.
  2. اضغط على Add New....
  3. اختر Project.
  4. ستظهر لك صفحة استيراد المستودعات من GitHub.
  5. ابحث عن اسم المستودع الذي أنشأته في الخطوة الأولى.
  6. اضغط على Import بجانب المشروع المطلوب.

ضبط إعدادات المشروع

  1. اكتب اسماً مناسباً لمشروعك في Project Name.
  2. إذا كان موقعك عبارة عن HTML وCSS وJavaScript عادي، اختر Other في Framework Preset إذا لم يتم اكتشافه تلقائياً.
  3. تأكد من أن Root Directory يشير إلى المجلد الذي يحتوي على index.html.
  4. اترك إعدادات Build and Output Directory الافتراضية لمشروع HTML ثابت بسيط، ما لم تكن لديك إعدادات خاصة.
تنبيه: إذا كان مشروعك مبنياً باستخدام React أو Next.js أو إطار عمل آخر، فقد تحتاج إلى إعدادات مختلفة عن مشروع HTML العادي.

04

نشر الموقع والحصول على الرابط النهائي

إطلاق مشروعك على الإنترنت بنجاح

تنفيذ عملية النشر Deploy

  1. راجع الإعدادات التي اخترتها في الخطوة السابقة.
  2. اضغط على زر Deploy.
  3. ستبدأ Vercel في تجهيز موقعك ونشره.
  4. انتظر حتى تنتهي عملية البناء والنشر بنجاح.
  5. ستظهر لك رسالة نجاح مع رابط الموقع.
  6. اضغط على Visit لفتح موقعك الإلكتروني الجديد.

ماذا بعد النشر؟

من أهم مميزات ربط GitHub بـ Vercel أن عملية النشر يمكن أن تصبح تلقائية.

عندما تعدل ملفات موقعك وترفع التغييرات إلى الفرع المرتبط بالنشر، ستكتشف Vercel التغييرات وتبدأ عملية نشر جديدة تلقائياً.

مبروك! أصبح موقعك متاحاً على الإنترنت. يمكنك مشاركة رابطه مع أصدقائك أو عملائك من أي مكان في العالم.

الأسئلة الشائعة

إليك إجابات عن أكثر الأسئلة التي قد تواجهك أثناء استضافة موقعك.

نعم، توفر Vercel خطة مجانية مناسبة للمشاريع الشخصية والتجارب التعليمية، مع وجود حدود استخدام وشروط للخطة المجانية.
لا، يمكنك تنفيذ الخطوات الأساسية المذكورة في هذا الدليل باستخدام متصفح الإنترنت فقط، دون تثبيت Git أو استخدام Terminal.
لا تحتاج إلى خبرة برمجية لتنفيذ خطوات رفع الملفات وربط الحسابات والنشر. لكن يجب أن تمتلك ملفات موقع جاهزة للنشر.
افتح مستودعك على GitHub، واختر الملف الذي تريد تعديله، ثم اضغط على أيقونة التعديل (Edit)، وأدخل التغييرات واحفظها باستخدام Commit changes. بعد ذلك ستبدأ Vercel عملية نشر جديدة تلقائياً عند تحديث فرع النشر المرتبط بالمشروع.
نعم، يمكنك ربط نطاق خاص مثل example.com من خلال إعدادات Domains داخل مشروعك في Vercel. قد تحتاج إلى شراء النطاق بشكل منفصل وضبط سجلات DNS وفق التعليمات المعروضة.
افتح صفحة Deployments داخل Vercel، واختر عملية النشر الفاشلة، ثم راجع Build Logs لمعرفة سبب المشكلة. تحقق من وجود index.html في المجلد الصحيح ومن إعدادات المشروع، ثم حاول النشر مجدداً.
