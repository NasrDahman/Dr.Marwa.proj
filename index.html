دليل خطوة بخطوة

كيف تستضيف موقعك عبر GitHub و Vercel؟

دليل مرئي تفاعلي يعتمد تماماً على الواجهات الرسومية وبدون أي سطر أوامر (CLI).

01

تجهيز ملفات الموقع

تأكد من أن ملفات موقعك جاهزة (مثل ملف index.html وملفات التنسيق والصور) ومجمعة داخل مجلد على حاسوبك الشخصي.

  • لا تحتاج لتثبيت برامج معقدة.
  • تأكد من صحة تسمية الصفحة الرئيسية.
02

إنشاء مستودع جديد على GitHub

ادخل إلى موقع GitHub، اضغط على علامة الزائد (+) أعلى اليمين ثم اختر New repository. سمّ المستودع واجعله عاماً (Public).

03

رفع الملفات مباشرة عبر المتصفح

داخل المستودع الذي أنشأته، اضغط على جملة "uploading an existing file". قم بسحب وإفلات جميع ملفات موقعك من حاسوبك إلى صفحة المتصفح، ثم اضغط على زر Commit changes الأخضر.

04

الربط والاستضافة عبر Vercel

ادخل إلى موقع Vercel وسجل الدخول باستخدام حسابك في GitHub. اضغط على Add New... ثم Project، واختر المستودع الخاص بك واضغط Deploy مباشرة بدون تعديل أي إعدادات!
