لماذا يجمع المحترفون بين GitHub و Vercel؟

انسَ طرق الرفع التقليدية المعقدة عبر الـ FTP. العالم اليوم يعتمد على النشر المستمر (CI/CD).

1. خزنة الكود الآمنة (GitHub)

يحفظ أكوادك في السحابة، ويتيح لك تتبع كل تعديل قمت به، والعودة لأي نسخة سابقة بضغطة زر دون خوف من ضياع ملفاتك.

2. سرعة خارقة (Vercel Edge)

منصة Vercel توزع موقعك على سيرفرات حول العالم (CDN)، مما يجعل موقعك يفتح في أجزاء من الثانية لأي زائر في أي دولة.

3. التحديث التلقائي السحري

بمجرد تعديل أي سطر في جهازك وإرساله لـ GitHub (`git push`)، يقوم Vercel تلقائياً ببناء الموقع وتحديثه للجمهور فوراً!

4 خطوات فقط تفصلك عن إطلاق موقعك

اتبع هذه الخطوات بالترتيب، ويمكنك نسخ الأوامر البرمجية مباشرة بضغطة زر.

1
المرحلة الأولى

تجهيز ملفات المشروع

تأكد أن ملف الصفحة الرئيسية لموقعك يحمل الاسم index.html لأن المتصفحات ومنصة Vercel تبحث عن هذا الملف تحديداً كواجهة أولى للموقع.

2
المرحلة الثانية

إنشاء مستودع (Repository) ورفع الكود

افتح حسابك في GitHub وأنشئ مستودعاً جديداً (New Repository)، ثم افتح موجه الأوامر (Terminal) داخل مجلد موقعك ونفذ هذه الأوامر: 

git init
git add .
git commit -m "First launch by Nasrallah Dahman"
git branch -M main
git remote add origin https://github.com/username/repo.git
git push -u origin main
3
المرحلة الثالثة ▲ Vercel

ربط حساب GitHub بمنصة Vercel

توجه إلى موقع vercel.com وسجل دخولك باستخدام حسابك في GitHub (Continue with GitHub). بعد الدخول، اضغط على زر Add New Project، ستظهر لك قائمة بمشاريعك الموجودة في GitHub، اضغط على Import بجانب اسم مشروعك.

4
المرحلة الأخيرة

الضغط على Deploy والاحتفال!

لا تغير أي إعدادات افتراضية، فقط اضغط على الزر السحري Deploy. خلال ثوانٍ ستظهر لك شاشة الاحتفال ورابط موقعك الرسمي الجاهز للمشاركة مع العالم!
