GitHub: المستودع وحافظة الأكواد

يمنحك مكاناً آمناً على السحابة لحفظ كافة ملفات موقعك مع متابعة كل تحديث تجريه، كل ذلك من خلال متصفح الويب المباشر.

  • إمكانية سحب وإفلات الملفات من جهازك مباشرة.
  • مجاني بالكامل وبدون قيود على عدد المستودعات العامة.
  • تتبع فوري للإصدارات وتأمين كامل لملفات المشروع.

Vercel: سرعة الإطلاق والأداء الفائق

المنصة الأكثر تميزاً في نشر وتوزيع صفحات الويب عبر شبكة سحابية فائقة السرعة مع ربط مباشر ومستمر مع GitHub.

  • نشر فوري بمجرد حفظ التعديلات (Auto Deployment).
  • شهادة تشفير وأمان (SSL) تلقائية ومجانية لجميع الروابط.
  • نطاق فرعي دائم وعالمي للمعاينة والمشاركة الفورية.

المرحلة 1

إنشاء مستودع GitHub ورفع الملفات

توجه إلى حسابك على GitHub عبر المتصفح واتبع الخطوات التالية:

  1. انقر على الزر الأخضر New لإنشاء مستودع جديد (Repository).
  2. حدد اسماً لمشروعك، وتأكد من اختيار الخيار Public.
  3. في صفحة التهيئة، اضغط على الرابط التفاعلي: uploading an existing file.
  4. قم بسحب ملفات موقعك (يجب أن يحتوي المجلد على ملف باسم index.html) وأفلتها في المتصفح، ثم انقر على زر Commit changes بالأسفل.
رفع ملفات الويب بالسحب والإفلات عبر واجهة المتصفح

المرحلة 2

التسجيل في Vercel بحسابك الحالي

عملية الدخول لا تتطلب أي ملء بيانات مطولة:

  1. توجه إلى الموقع الرسمي: vercel.com.
  2. اضغط على خيار Sign Up من أعلى الصفحة.
  3. اختر الدخول المباشر بواسطة Continue with GitHub.
  4. وافق على طلب التفويض (Authorize) ليتم ربط الحسابين معاً بسلاسة تامة.
المرحلة 3

استيراد المستودع (Import Project)

من داخل لوحة التحكم الرئيسية الخاصة بـ Vercel:

  1. انقر على الزر البارز Add New... ثم اختر Project.
  2. ستعرض لك المنصة المستودعات المتوفرة على حسابك؛ حدد المشروع المطلوب.
  3. اضغط على زر Import المجاور لاسم المستودع.
  4. اترك كافة خيارات الإعدادات الافتراضية كما هي (Framework / Root Directory).

المرحلة 4

إتمام النشر (Deploy) واستلام الرابط

اللمسة الأخيرة ليصبح موقعك متاحاً لكل العالم:

  1. اضغط على الزر الكبير Deploy.
  2. انتظر قرابة 20 إلى 40 ثانية بينما يكتمل بناء الملفات وتوزيعها على الخوادم.
  3. ستظهر شاشة الاحتفال مع عبارة التهنئة المعتادة، متبوعة برابط حي لموقعك ينتهي بـ vercel.app يمكنك نسخه ومشاركته مباشرة!

الأسئلة الأكثر شيوعاً

كل ما تحتاج لمعرفته حول الصيانة والتحديثات المستقبلية

هذه نقطة القوة في هذا الربط! بمجرد أن ترفع ملفات محدثة أو تجري أي تعديل داخل مستودع GitHub عبر المتصفح، سيكتشف Vercel ذلك فوراً ويعيد نشر الموقع بالنسخة الحديثة دون أي تدخل منك.
الخدمة مجانية 100% لخطة الاستخدام الشخصي والمشاريع التعريفية، وتشمل شهادات الأمان (SSL) والنطاقات التلقائية مع حزمة استهلاك بيانات سخية جداً وبدون الحاجة لربط أي وسيلة دفع.
خوادم الويب العالمية تعتبر اسم index.html هو نقطة الدخول الافتراضية؛ فعندما يفتح أي مستخدم رابط الموقع دون تحديد مسار صفحة معينة، يقوم الخادم تلقائياً بعرض هذا الملف أولاً.
